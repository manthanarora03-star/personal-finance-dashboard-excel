# Personal Finance Dashboard (Excel)

An interactive Excel dashboard created to analyze and visualize personal expense data using pivot tables and charts.

## Features
- Expense categorization
- Category-wise spending analysis
- KPI cards for financial insights
- Interactive charts and visualizations

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Data Formatting
